Live in three steps

Everything happens on GitHub's website. No terminal, no package manager.

Use the template

Click Use this template and name the new repository your-name.github.io.

Edit two files

Fill in config.yml, paste your papers into publications.bib, drop a photo in assets/.

Turn on Pages

Settings → Pages → Deploy from a branch → main. Every later commit updates the site.

# config.yml
name: Mochi Purrington
name_alt: 糯米喵            # shown on the Chinese page
role: PhD Student in Computer Science
affiliation: "[Aoao University](https://example.edu)"
avatar: assets/avatar.webp
email: mochi@example.edu
links:
  - { label: Scholar, url: "https://scholar.google.com/" }
  - { label: GitHub,  url: "https://github.com/" }
callout: I'm on the **job market in 2027**.

theme:
  style: margin       # or: catalog
% publications.bib · straight from Google Scholar
@inproceedings{purrington2026glassbox,
  title    = {Glass-Box Agents: Faithful Self-Explanation ...},
  author   = {Purrington, Mochi and Okafor, Daniel and ...},
  year     = {2026},
  abbr     = {NeurIPS},
  award    = {Oral Presentation (Top 1.2%)},
  selected = {true},
}

Small, and complete

Everything an academic homepage needs, in about 100 KB of plain JavaScript and CSS.

BibTeX in, papers out

Paste from Scholar, DBLP or Zotero. LaTeX accents, @string macros and equal-contribution marks just work; your name is bolded.

Search and filter

Press / to search titles, authors and venues as you type, with hits highlighted. Filter by topic.

Two languages, one switch

Add config.zh.yml with only the fields you want translated, and a 中 / EN button appears.

Pages, not a long scroll

Each top-bar item opens its own page with its own address, so Back, bookmarks and shared links work.

Dark mode and phones

Both looks follow the system theme, fit a phone screen, and print as a clean one-pager.

Quiet motion

A sliding top-bar highlight, frosted glass on scroll, content that rises in. Honors reduce-motion.

Friendly errors

A typo in YAML or BibTeX shows the file, the line and a hint instead of a blank page.

Zero build

No Node, no Ruby, no Jekyll. Two text files on any static host: GitHub Pages, Netlify, your department server.
